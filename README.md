# WasteGuard

**Predict. Prevent. Resolve.**

Hackathon-ready Smart City / GovTech prototype for predictive waste management.

## Features

- Citizen waste reporting with clearly labeled demo AI analysis
- Complaint lifecycle tracking
- Admin Smart Waste Command Center
- Predictive hotspot intelligence using simulated demo values
- Smart route visualization
- Worker task dashboard
- Before/after cleanup verification
- Waste awareness with English + Hindi guidance
- Clean City Rewards
- Responsive mobile UI
- Local persistence using browser localStorage

## Important prototype note

AI analysis, risk scores, route savings and prediction values are **DEMO/SIMULATED** unless connected to a real model/data source. The app does not claim real AI accuracy.

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```

The generated `dist` folder can be deployed to a static host such as GitHub Pages, Netlify, or Vercel.

## GitHub
